## Selected Projects

Each project below is a **live, deployed client build** — not a demo or tutorial project.

### Global Minds Consultants — Consultancy Platform with CRM-Style Admin
**Problem:** A consultancy needed a modern client-facing site backed by real internal tooling for managing their business, not just static pages.
**Solution:** Built a clean, modern consultancy website paired with a full CRM-style admin dashboard covering content management, event management, blog publishing, and team management, with analytics/reporting graphs for oversight.
**Stack:** React.js, Node.js, Express.js, MongoDB
**Engineering highlights:** Admin dashboard architecture, role-based content management, CRM-style data modeling, analytics visualization
🔗 [Live site](https://globalmindsconsultants.com/)

### Catering Bestilling NO — Multi-Vendor Marketplace (Norway)
**Problem:** A Norway-based catering business needed a two-sided marketplace connecting customers placing orders with vendors fulfilling them — including compliant invoicing.
**Solution:** Built both the customer-facing ordering platform and the vendor/admin panel, with an end-to-end order and booking flow, payment handling, invoice generation, and integration with Norway's **EHF e-invoicing** API standard.
**Stack:** React.js, Node.js, Express.js, MongoDB
**Engineering highlights:** Multi-sided marketplace architecture, order/booking workflow, payment & invoice generation, EHF API integration, vendor-facing admin panel
🔗 [Client site](https://catering-bestilling-no.vercel.app/) · [Vendor/Admin panel](https://bestilling-admin-panel.vercel.app/)

### Exlon Tech — Corporate Site & Distribution/POS System
**Problem:** A software house needed a polished, animated public-facing website, plus internal retail infrastructure for a distribution business.
**Solution:** Delivered a fully animated, professionally designed corporate website with a clean backend and responsive service pages, alongside a separate distribution and point-of-sale (POS) management system for retail operations.
**Stack:** React.js, Node.js, Express.js, MongoDB
**Engineering highlights:** Animated UI/UX, responsive design across services pages, backend content management, retail/distribution data handling
🔗 [Corporate site](https://exlontech.com/) · [Distribution/POS system](https://distribution.exlontech.com/)

### HQA Fund — 45+ Page Platform with International Payments
**Problem:** An education/fund-related client needed a large, highly polished site with real booking and international payment capability.
**Solution:** Built a 45+ page, heavily animated React front end backed by a Laravel API, supporting event booking and integrated international payment methods — **Stripe, PayPal, Google Pay, and Apple Pay**.
**Stack:** React.js (animation-heavy), Laravel, PHP, REST APIs
**Engineering highlights:** Large-scale multi-page architecture, front-end animation at scale, Laravel API design, multi-provider international payment integration, event booking system
🔗 [Live site](https://hqafund.org/)

### Alpha Trading Society — Trading Community Platform
**Problem:** A trading education/community needed a full platform to support their offering online.
**Solution:** Built the complete platform end-to-end.
**Stack:** React.js, Node.js, Express.js, MongoDB
🔗 [Live site](https://alphatradingsociety.com/)
